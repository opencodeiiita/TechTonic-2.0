# Task 01 – Responsive Section Using Semantic HTML & CSS

## What I understood from this task
The goal of this task was to practice writing clean and meaningful HTML using
semantic tags and style a section using pure CSS without any frameworks or
JavaScript. The task mainly focused on structure, readability, and making the
layout responsive for different screen sizes rather than creating a complex
design.

## How I implemented the solution
I added a new section called “Why TechTonic” to the page. I used semantic HTML
elements like section, header, and article to clearly define the structure and
purpose of the content. Each feature was placed inside an article tag to make
the content easy to understand and well-organized.

For styling, I used Flexbox to create a card-based layout. Flexbox was chosen
because it allows easy alignment and spacing between elements and works well
for responsive layouts. I used a media query to change the layout on smaller
screens so that the cards stack vertically instead of staying in a row.

## What I learned from this task
Through this task, I learned how semantic HTML improves code readability and
makes the structure of a webpage more meaningful. I also learned how Flexbox
can be used to create clean layouts without relying on CSS frameworks and how
media queries help in making designs responsive.

## What is good about my solution
The section is clean, readable, and visually structured using cards. The layout
adapts properly on both desktop and mobile screens without breaking. The code
is simple, organized, and easy to understand, which makes it maintainable.

## What could be improved or what felt difficult
Deciding proper spacing and font sizes without using any framework felt a bit
challenging. With more practice, I think I can improve visual consistency and
typography choices.

## Other thoughts while working on this task
This task helped me understand that even simple sections require proper planning.
It made me more confident in writing HTML and CSS from scratch and thinking
about responsiveness while designing a layout.
